# Wonder Lab — Beauty Salon Lecce

Sito one-page statico (HTML, CSS e JavaScript, senza dipendenze né build).

- `index.html` — pagina principale
- `css/styles.css` — stili
- `js/main.js` — menu, FAQ, timeline, "Scopri di più", validazione del form
- `assets/img/` — logo e fotografie dei servizi
- `privacy-policy.html`, `cookie-policy.html` — bozze da completare

## Da completare prima della messa online definitiva
- Collegare il form a un servizio reale tramite l'attributo `data-endpoint` in `index.html`.
- Sostituire la foto della hero (Unsplash, illustrativa) con una fotografia autentica.
- Completare le parti evidenziate di Privacy e Cookie Policy.
- Aggiornare il tag `canonical` con il dominio definitivo.
